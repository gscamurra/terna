# carousel-kpi

Custom **carousel** block. Purpose: Boxed KPI slider with vertical icon navigation and large stat figures.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide. Cell 1: category icon (used as the nav button). Cell 2: title (heading), reference date paragraph, then stats: each paragraph starting with a number starts a stat, followed by its label and delta (+/-, "vs") paragraphs; alternatively a list with one item per stat, or one extra cell per stat.

## Supported variations

No variations.
