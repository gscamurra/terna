# carousel-hero

Custom **carousel** block. Purpose: Full-viewport rotating hero with photo slides, overlay text and labelled tab navigation.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide. Cell 1: background image. Cell 2: title (heading), description, CTA link (a YouTube/Vimeo/.mp4 link opens a video dialog instead). Optional cell 3: short tab label (defaults to the slide heading). Rotates automatically with a stop/play button unless reduced motion is preferred.

## Supported variations

No variations.
