# hero-banner

Custom **hero** block. Purpose: In-page photo banner with eyebrow, title, text and link overlaid at left.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: background image; row 2: eyebrow paragraph, title (heading), optional description, CTA link. The image may also be authored inside the text cell.

## Supported variations

- `no-overlay` (`Hero Banner (no overlay)`): removes the 60% black image overlay, for photos that are already dark (source "Terna incontra" banner). Default keeps the overlay (source "Lavora con noi" banner).
