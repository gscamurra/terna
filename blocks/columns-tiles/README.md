# columns-tiles

Custom **columns** block. Purpose: Fixed row of equal bordered tiles, each with its own mixed content.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile row, one cell per tile. In a tile: optional short first paragraph = eyebrow; heading = title; a paragraph whose link text is its own URL becomes an embedded iframe; a list with more than 3 items is paginated with dots; two or more images turn the tile into an image slider (each image starts a slide); a trailing link-only paragraph is the tile CTA pinned to the bottom.

## Supported variations

No variations.
