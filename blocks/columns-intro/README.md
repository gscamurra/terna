# columns-intro

Custom **columns** block. Purpose: Two-column intro band: large heading and link on the left, body text on the right.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells. The cell holding the heading is the lead column (placed first); the other cell holds body paragraphs. Link-only paragraphs are marked as CTAs. Place it in a section with a style (e.g. light-blue) for the colored band.
