# cards-promo

Custom **cards** block. Purpose: Text-only promo cards, each with its own solid background color and white text.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card. Optional image cell; text cell with eyebrow paragraph, title (heading), description and a trailing CTA link. Extra text cells are merged into the body.

## Supported variations

No variations.
